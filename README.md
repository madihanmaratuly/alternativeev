# 🌐 ХРОНОСФЕРА — Симулятор альтернативной истории

Интерактивный русскоязычный веб-сайт, позволяющий исследовать любые гипотетические развилки истории («Что было бы, если...»), включая подробный сценарий: **«Что было бы, если бы люди не изобрели интернет?»**.

---

## ⚡ Быстрый запуск

У вас есть два простых способа открыть сайт:

### Вариант 1: Прямое открытие в браузере (без серверов)
Просто дважды кликните по файлу **`index.html`** в проводнике Windows — сайт откроется в вашем браузере (Edge, Chrome, Яндекс.Браузер и т.д.) и будет работать на 100% без дополнительных настроек.

### Вариант 2: Запуск через встроенный PowerShell сервер
В проводнике щелкните правой кнопкой мыши по **`run_server.ps1`** $\rightarrow$ *«Выполнить с помощью PowerShell»*  
Либо запустите в терминале:
```powershell
powershell -ExecutionPolicy Bypass -File .\run_server.ps1
```
Сервер запустится на порту `8080` и автоматически откроет вкладку `http://localhost:8080/`.

## 🧭 Возможности приложения

1. **Любой пользовательский запрос**:
   - Можно ввести произвольную фразу: *«Что было бы, если бы люди умели телепортироваться?»*, *«Что если бы Наполеон победил при Ватерлоо?»*, *«Что если бы не изобрели пластик?»* и т.д.
2. **Быстрые пресеты**:
   - 🌐 **Что если бы не изобрели интернет?** (сверхскоростная пневмопочта, киоски записи лазерных дисков, живое общение без соцсетей).
   - 🦖 **Динозавры не вымерли** (метеорит пролетел мимо, эра био-городов и прирученных гигантов).
   - 🏛️ **Римская империя не пала** (Pax Aeterna, ранняя научная революция и паровые легионы).
   - ⚡ **Электричество не открыли** (неостимпанк, оптический телеграф, машины Беббиджа).
   - 📚 **Александрийская библиотека уцелела** (выход в космос на 500 лет раньше).
3. **Глубокая аналитика каждой реальности**:
   - **Точка бифуркации**: когда и почему произошел раскол.
   - **Шкала дивергенции**: процент отклонения ветви от нашего мира.
   - **Интерактивный таймлайн**: ключевые эпохи от развилки до 2060+ года.
   - **4 сферы влияния**: Наука и технологии, Геополитика, Быт и культура, Экономика.
   - **«Эффект бабочки»**: парадоксальное неожиданное последствие.
   - **Подлинный ретро-артефакт**: вырезка из газеты той реальности или правительственный указ со штампом.
   - **Ветвления («Что дальше?»)**: развилки следующего порядка.
4. **Интерактивные технологии**:
   - Web Audio API (звуковые эффекты варп-прыжка, кликов и печати без внешних файлов).
   - Particle Canvas (плавный фоновый квантовый поток частиц).
   - Сохранение в Избранное (LocalStorage).
   - Экспорт в PDF / Печать со стилизацией под архивный документ.
5. **Опциональный Gemini API**:
   - В настройках (шестеренка в шапке) можно ввести свой ключ Google Gemini API, если вы хотите подключить неограниченную нейросетевую генерацию текстов. По умолчанию работает встроенный автономный движок.
